# CYRA Mathematical Methodology & Threat Modeling

## 1. Shannon Entropy Delta
Shannon entropy is calculated over a byte sequence of length $N$:
$$H(X) = - \sum_{i=0}^{255} P(x_i) \log_2 P(x_i)$$
Where $P(x_i)$ is the empirical byte frequency. Typical plain text and structured code files exhibit $H \approx 3.5 - 5.0$ bits/byte. Encrypted payloads generated by ransomware algorithms (AES-256-CBC, ChaCha20) exhibit near-maximal entropy:
$$H_{\text{encrypted}} \approx 7.85 - 7.99 \text{ bits/byte}$$
CYRA computes $\Delta H = H_{\text{post}} - H_{\text{pre}}$. A delta $\Delta H \ge +0.25$ indicates an acute cryptographic transformation.

## 2. Multi-Model Hybrid Verification
1. **Random Forest Classifier**: Orthogonal ensemble of decorrelated decision trees evaluating write burst velocities, extension mutations, and parent process lineage.
2. **XGBoost Classifier**: Gradient boosted trees penalizing false positives on benign developer compilation bursts (e.g. `tsc`, `gcc`) and compression tools (e.g. `7z.exe`).
3. **Isolation Forest Anomaly Model**: Evaluates isolation path length $h(x)$ across normalized behavioral coordinates:
$$s(x, n) = 2^{-\frac{E(h(x))}{c(n)}}$$
Shorter path lengths correspond to high anomaly scores.

## 3. Dynamic Evidence Fusion Formula
Risk score ($R \in [0, 100]$) is computed through calibrated convex combination:
$$R = \min\left(100, \left( w_{\text{sup}} S_{\text{sup}} + w_{\text{anom}} S_{\text{anom}} + w_{\text{ctx}} S_{\text{ctx}} + w_{\text{temp}} S_{\text{temp}} \right)\right)$$
Default calibrated weights:
- $w_{\text{sup}} = 0.35$ (Supervised RF + XGBoost concordance)
- $w_{\text{anom}} = 0.25$ (Isolation Forest anomaly score)
- $w_{\text{ctx}} = 0.30$ (Canary decoy breach, entropy delta, extension tampering)
- $w_{\text{temp}} = 0.10$ (10-second temporal sliding window velocity)
